# mlabo-org

Personal Codex lab snapshots.

These repositories are public reference snapshots from my personal Codex plugin, skill, and workflow experiments. They are shared for people who can read the source, understand the assumptions, and adapt them with their own Codex.

They are not supported products, maintained frameworks, or general-purpose distributions.

No free setup support. No compatibility guarantee. No active roadmap.

If something is unclear, ask your own Codex first.

Some existing public repositories are kept as legacy references because they may be linked from articles or older notes. They are not necessarily in sync with my current local environment.

## Intended Audience

These repositories are for people who can inspect, fork, and maintain their own setup.

If your Codex cannot make sense of a repository here, you probably should not install it yet.

## Support Policy

These repositories are shared as-is.

I do not provide free setup support, troubleshooting, customization, compatibility fixes, or environment-specific guidance.

Issues and pull requests may be ignored or closed without explanation. Critical security or privacy problems may be considered, but there is no response-time guarantee.

If you need hands-on support, custom adaptation, or guaranteed maintenance, that is paid work.

# mlabo-org

個人の Codex 実験環境から切り出した snapshot 置き場です。

ここにある repository は、作者の個人的な Codex plugin、skill、workflow 実験から切り出した公開参照 snapshot です。ソースを読み、前提を理解し、自分の Codex と一緒に改変できる人向けに共有しています。

これは、サポート付き製品、継続保守される framework、汎用配布物ではありません。

無償サポート、互換性保証、ロードマップはありません。

分からないことは、まず自分の Codex に聞いてください。

既存の公開 repository の一部は、記事や過去の notes から参照されている可能性があるため legacy reference として残しています。現在のローカル環境と同期しているとは限りません。

## 想定読者

ここにある repository は、自分で中身を調べ、fork し、自分の環境に合わせて維持できる人向けです。

あなたの Codex が repository の意味を理解できない場合、まだ導入しないほうがよい可能性があります。

## サポート方針

これらの repository は現状のまま共有しています。

無償での導入支援、トラブルシュート、個別カスタマイズ、互換性対応、環境別の案内は行いません。

issue や pull request は、説明なく無視または close する場合があります。重大なセキュリティ問題やプライバシー問題は確認対象にする可能性がありますが、対応期限の保証はありません。

個別支援、環境適合、継続保守が必要な場合は、有償対応の範囲です。
