# mlabo-org

Personal AI-agent lab snapshots.

These repositories are public reference snapshots from my personal tools, plugins, skills, and workflow experiments for AI coding agents, mainly Claude Code and Codex. They are shared for people who can read the source, understand the assumptions, and adapt them with their own coding agent.

They are not supported products, maintained frameworks, or general-purpose distributions.

No free setup support. No compatibility guarantee. No active roadmap.

If something is unclear, ask your own coding agent first.

## How These Are Made

Most of the code here is written by AI coding agents (currently Claude Code first, Codex second) under my direction. I decide what to build, review the results, and test them on my own Mac, but I do not hand-review every line.

The tools are built for my own environment: macOS, local-first, and personal use. Paths, installed apps, accounts, and plans that a repository assumes may not match yours.

Read the code before you run it, especially anything that starts a local server, drives a browser, or calls an AI service with your account.

Some existing public repositories are kept as legacy references, and some are archived, because they may be linked from articles or older notes. They are not necessarily in sync with my current local environment, and some of them still describe a Codex-only setup.

Not everything I build is published. A tool I mention in an article or post may be private on purpose.

## Intended Audience

These repositories are for people who can inspect, fork, and maintain their own setup.

If your coding agent cannot make sense of a repository here, you probably should not install it yet.

## Support Policy

These repositories are shared as-is, under the license in each repository (MIT unless stated otherwise).

I do not provide free setup support, troubleshooting, customization, compatibility fixes, or environment-specific guidance.

Issues and pull requests may be ignored or closed without explanation. Critical security or privacy problems may be considered, but there is no response-time guarantee.

If you need hands-on support, custom adaptation, or guaranteed maintenance, that is paid work.

# mlabo-org

個人の AI エージェント実験環境から切り出した snapshot 置き場です。

ここにある repository は、作者が AI コーディングエージェント（主に Claude Code と Codex）向けに作った個人的なツール、plugin、skill、workflow 実験から切り出した公開参照 snapshot です。ソースを読み、前提を理解し、自分のコーディングエージェントと一緒に改変できる人向けに共有しています。

これは、サポート付き製品、継続保守される framework、汎用配布物ではありません。

無償サポート、互換性保証、ロードマップはありません。

分からないことは、まず自分のコーディングエージェントに聞いてください。

## 作り方

ここにあるコードの大半は、作者の指示のもとで AI コーディングエージェント（現在は Claude Code が主、Codex が従）が書いたものです。何を作るかを決め、結果を確かめ、自分の Mac で動作を確認するのは作者ですが、全行を人の手でレビューしているわけではありません。

ツールは作者自身の環境向けに作っています。macOS、ローカル中心、個人利用が前提です。repository が前提とするパス、インストール済みのアプリ、アカウント、契約プランは、あなたの環境と一致しないことがあります。

実行する前にコードを読んでください。特に、ローカルサーバーを起動するもの、ブラウザーを操作するもの、あなたのアカウントで AI サービスを呼ぶものは注意してください。

既存の公開 repository の一部は、記事や過去の notes から参照されている可能性があるため legacy reference として残しており、archive 済みのものもあります。現在のローカル環境と同期しているとは限らず、Codex だけの構成を前提にした説明が残っているものもあります。

作ったものすべてを公開しているわけではありません。記事や投稿で触れたツールが、意図して非公開になっていることもあります。

## 想定読者

ここにある repository は、自分で中身を調べ、fork し、自分の環境に合わせて維持できる人向けです。

あなたのコーディングエージェントが repository の意味を理解できない場合、まだ導入しないほうがよい可能性があります。

無償での導入支援、トラブルシュート、個別カスタマイズ、互換性対応、環境別の案内は行いません。

issue や pull request は、説明なく無視または close する場合があります。重大なセキュリティ問題やプライバシー問題は確認対象にする可能性がありますが、対応期限の保証はありません。
